语法速查 
@meta            元数据（id/title/badge/start…）
@items           id: 图标 名称 | 描述
@scene 场景id    属性：label/bg/amb/fx/mode/style

旁白行
名字: 台词
名字(内心): 内心独白
! 强调行
文中 [词语|词id] 为互动词

+ 词id:              点击反应块（缩进更深）
+ 词id (once):       执行一次后置灰
+ 词id @ 道具id:     对词使用道具
    : 文本 / get / set / unset / clue
    sfx / fx / amb / hint / off
    goto 场景id / nav 链接
    if 条件: 单行动作
when 条件: 动作      场景级触发（用于揭示出口）

持久化说明 
草稿自动保存在本浏览器（localStorage），
换浏览器/清缓存会丢失。

定稿流程：点「下载 .js」，把文件放进
仓库 scripts/ 目录并提交 git——
仓库才是剧本的唯一真源。

草稿试玩的存档与正式游戏进度互相隔离。
